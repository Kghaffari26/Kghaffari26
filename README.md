# Hi there 👋

I build **autonomous AI agents and AI-powered web apps**: scheduled agents that investigate real data, products with Claude built in, and the guardrails that make them trustworthy (sourced numbers, cost caps, evals, human approval for writes).

### 🔭 Featured: [Agents Hub](https://kghaffari26.github.io/agents-hub/)

Four AI agents that track **housing, the economy, federal contracts, and code**, refreshed automatically on GitHub Actions with every number sourced and every LLM dollar published (runs cost cents).

| Repo | What it does |
|---|---|
| [agents-hub](https://github.com/Kghaffari26/agents-hub) | Static Next.js dashboard site that assembles each agent's output (Playwright + axe tested, Lighthouse 95+) |
| [agents-core](https://github.com/Kghaffari26/agents-core) | Shared Python framework: budgeted tool-use loop, HTTP cache, number guard, tracing, evals, data-branch publisher |
| [real-estate-agent](https://github.com/Kghaffari26/real-estate-agent) | 50 U.S. metros from Redfin, Zillow, FRED and Census, with weekly briefs and anomaly investigations |
| [fed-agent](https://github.com/Kghaffari26/fed-agent) | ~24 macro indicators, yield curve, word-level FOMC statement diffs, "what's driving this" |
| [sam-agent](https://github.com/Kghaffari26/sam-agent) | Scores SAM.gov / Grants.gov opportunities against a business profile; bid research via USAspending |
| [repo-maintain-agent](https://github.com/Kghaffari26/repo-maintain-agent) | Repo health, triage and changelogs; drafts fix PRs behind human approval |
| [agents-mcp](https://github.com/Kghaffari26/agents-mcp) | Read-only MCP server so Claude and other MCP clients can query all of the above |
